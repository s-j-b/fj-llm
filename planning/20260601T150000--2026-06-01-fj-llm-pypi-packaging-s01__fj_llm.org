* Overview

Make =fj_llm= a proper, versioned, publicly-installable PyPI package. Two
consumers drive this: Enlightapp (company project, Firebase Functions on Cloud
Run) and a personal LLM pipeline. Both will pin to a released version via
=requirements.txt=. PyPI was chosen over GitHub-based pip install so that
Enlightapp's CI/CD needs no GitHub credentials, and any future Enlightapp
engineer can install it without setup.

* Decision Log

- Distribution target :: PyPI (not GitHub-based pip install, not vendoring)
- Reason :: Two independent consumers; one is a company project that must not
  depend on personal GitHub credentials in CI. =pip install fj_llm==X.Y.Z=
  works anywhere.
- Starting version :: =0.2.0= (=0.1.0= was cut from an older, simpler client;
  this release brings meaningful additions: fallback support, quota detection,
  Google provider, cost logging, stdlib logging)

* Dependency Notes

=fj_llm= itself only needs:
- =requests>=2.25.0=
- =pyyaml>=5.4.0=

No provider SDK is required — all providers are called via raw HTTP. This is
intentional: keeps the package lightweight and avoids pinning to any provider's
SDK release cycle.

Test-only dependencies (not shipped):
- =pytest=
- (no mock library needed — =unittest.mock= is stdlib)

* Cost Log Path Design

The jupeserver version hardcodes =Path(__file__).parent.parent / 'auto' / 'llm_costs.jsonl'=,
which only works inside the jupeserver repo layout. The standalone version will:
- Default to =~/.local/share/fj_llm/costs.jsonl=
- Allow override via a =cost_log= key in the config file or =FJ_LLM_COST_LOG=
  env var
- Silently skip logging if the path is not writable (same "never crash the
  caller" contract as the current code)
